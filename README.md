# Unofficial browser modernization for HONDA workshop manual

## Description
An unofficial browser modernization for official HONDA Civic 8 5D workshop manual. This is a refactor code to make the content viewable for nowadays browsers and no longer open it with Internet Explorer 8 compatibility mode.

Manual content &copy; Honda Motor Co., Ltd. All rights reserved.

## Usage
### Online
Now running on www.joelfaura.com/civic-8-workshop-manual

### Self-hosted
You can host the workshop manual 
#### Requisites
- Windows 10 or higher
- Python installed (v X or higher)
- Python library http.server
#### Execution
Once you have all requisites, execute "manual.lnk" file on the root folder.
