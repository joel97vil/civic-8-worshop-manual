Dépistage des pannes : 76

DTC 76 :  Capteur d'accélération latérale (logiciel)


NOTA : Si le code 76 est accompagné de l'un des codes suivants, terminer par le diagnostic du code 76.

DTC 25 : Capteur de taux de lacet (unité de capteur)
DTC 26 : Capteur d'accélération latérale (unité de capteur)
DTC 72 : Capteur d'angle de braquage (logiciel)
DTC 74 : Capteur de taux de lacet (logiciel)
DTC 75 : Capteur d'accélération latérale (panne de raccord)

1.Mettre le contact (II).

2.Effacer le code à l'aide du HDS.

3.Tester le véhicule en ligne droite.

4.Lire les codes au HDS.

Le DTC 76 est-il indiqué ?


OUI - Aller à 5.


NON - Panne intermittente, système OK pour le moment. La cause la plus probable réside dans l'état extrême de la chaussée parcourue.n


5.Couper le contact.

6.Substituer un capteur d'amplitude du lace/accélération latérale en bon état.

7.Mettre le contact (II).

8.Effacer le code à l'aide du HDS.

9.Faire un essai sur route en ligne droite.

10.Contrôler les codes avec le HDS.

Le DTC 76 est-il indiqué ?


OUI - Remplacer l'unité de commande-modulateur VSA.n


NON - Remplacer le capteur de taux de lacet/accélération latérale d'origine.n
