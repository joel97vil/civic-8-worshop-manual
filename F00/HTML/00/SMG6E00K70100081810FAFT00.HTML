Dépistage des DTC : 81

DTC 81 :  Unité CPU


1.Mettre le contact (II).

2.Effacer le code à l'aide du HDS.

3.Couper le contact, puis le remettre (II) à nouveau.

4.Lire les codes au HDS.

Le DTC 81 est-il indiqué ?


OUI - Remplacer l'unité de commande-modulateur ABS.n


NON - Panne intermittente; système en ordre pour le moment.n
