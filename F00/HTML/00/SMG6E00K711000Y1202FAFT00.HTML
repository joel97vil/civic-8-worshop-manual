Dépistage des pannes : B1202 (P)

Codes B1202 ou témoin de code P :  Erreur interne du module de commande de climatisation


NOTA : Vérifier l'état de la batterie et le circuit de charge, moteurs L13A7, R18A2.

1.Effacer le code à l'aide de l'HDS.

2.Couper puis mettre le contact (II).

3.Effectuer l'autodiagnostic au HDS ou à l'unité de commande de clim.

4.Vérifier les codes.

Le code B1202 ou P est-il affiché ?


OUI - En cas de panne de l'unité de commande de clim, la remplacer  .n


NON - Panne intermittente; le module de commande de climatisation est en ordre pour le moment.n
