Dépistage des pannes du système audio - Pas de chargement de disque audio

Pas de chargement de disque audio


NOTA :
  • Les étiquettes de disque ne doivent pas être utilisées dans l'unité audio. Elles peuvent endommager le mécanisme du lecteur.
  • S'assurer que le CD est compatible avec le système (voir le manuel du propriétaire pour de plus amples informations).

1.Insérer un disque en bon état pour voir si le symptôme peut être reproduit.

Le disque se charge-t-il ?


OUI - Fonctionnement normal. Si le disque se charge normalement dans le casier inférieur, mais ne peut être lu, passer à "pas de lecture de disque audio".n


NON - Passer à 2.


2.Insérer un autre disque.

Le disque se charge-t-il ?


OUI - Le disque original est défectueux.n


NON - Remplacer l'unité audio.n
