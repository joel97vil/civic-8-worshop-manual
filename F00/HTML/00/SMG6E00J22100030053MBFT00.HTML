Réécriture des données ODO (totalisateur) et transfert des infos de maintenance sur un nouveau module de commande des indicateurs


NOTA :
  • Si le HDS retrouve les données ODO du module de commande d'indicateurs, la valeur ODO de l'écran d'informations multiples sera ‘‘— — —", rendant la fonction ODO inutilisable, et le HDS sera incapable de retrouver les valeurs ODO additionnelles.
  • Il n'est pas possible de réécrire sur un module de commande des indicateurs qui ne communique pas.
  • Obtenir un nouveau module de commande des indicateurs avant la réécriture.

1.Avant de remplacer le module de commande des indicateurs, connecter le HDS au DLC.

2.Sélectionner GAUGES (indicateurs) dans le menu BODY ELECTRICAL SYSTEM SELECT (sélection de circuit électrique de caisse).

3.Sélectionner "GAUGE CONTROL MODULE REPLACEMENT (ODO rewrite)'' (remplacement de module de commande d'indicateurs (réécriture ODO) dans le menu ADJUSTMENT (réglage), et suivre les instructions affichées pour récupérer la valeur ODO.

4.Remplacer le module de commande d'indicateurs.

5.Suivre les instructions affichées pour écrire la nouvelle valeur ODO sur le nouveau module de commande des indicateurs.
