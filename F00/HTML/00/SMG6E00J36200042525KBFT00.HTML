Remplacement du DVD-ROM

NOTA : Quand le DVD-ROM est réintroduit ou remplacé, une correspondance de carte doit être effectuée.

1.Mettre le contact (II).

2.Ouvrir le couvercle avant (A) de l'unité de navigation (B) placée derrière la boîte à gants.

 

3.Appuyer sur la touche EJECT (C).

4.Retirer le DVD-ROM.

5.Introduire le nouveau DVD-ROM.

6.Refermer le couvercle avant. Ne pas couper le contact avant l'importation des données dans l'unité de navigation.

NOTA : Après intervention, le couvercle avant doit être fermé. Si vous lancez le système de navigation avec le couvercle avant ouvert, l'écran indiquera ‘‘Volet d'unité de navigation ouvert ou pas de DVD installé. Vérifier le circuit".
