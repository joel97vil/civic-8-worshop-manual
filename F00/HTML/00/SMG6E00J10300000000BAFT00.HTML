Codes d'erreur du système audio

Le système audio affiche des codes d'erreur lorsqu'un problème de changeur de CD, de disque audio ou de code antivol est détecté.

Code d'erreur affiché Cause probable Solution 
CD DISC Ne peut lire le disque. Ejecter le disque et en essayer un autre. 
ERROR Problème de lecteur de disque. Un problème fréquent est l'étiquette se détachant du disque dans le lecteur. Essayer d'éjecter le disque et en essayer un autre. Si le problème persiste, remplacer l'unité audio. 
CD HEAT Le lecteur de disque est chaud. Ceci peut se produire si le véhicule stationne en plein soleil pendant toute la journée. Stationner le véhicule dans un emplacement plus frais pendant un certain temps et tester à nouveau le lecteur de disque. Si le code d'erreur est toujours présent, essayer un autre disque. Si le code d'erreur est toujours présent, remplacer l'unité audio.
