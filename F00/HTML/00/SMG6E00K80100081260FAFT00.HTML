Dépistage des pannes DTC : 26

DTC 26 :  Capteur d'accélération latérale (unité de capteur)


1.Mettre le contact (II).

2.Lire les codes au HDS.

Codes 92 et 91 mémorisés en même temps que le code 26 ?


OUI - Diagnostiquer le code 91 ou 92 : Code 91, code 92.n


NON - Aller à 3.


3.Couper le contact.

4.Substituer un capteur d'amplitude du lace/accélération latérale en bon état.

5.Mettre le contact (II).

6.Effacer le code à l'aide du HDS.

7.Couper le contact, puis le remettre (II) à nouveau.

8.Lire les codes au HDS.

Le DTC 26 est-il indiqué ?


OUI - Remplacer l'unité de commande-modulateur VSA.n


NON - Remplacer le capteur de taux de lacet/accélération latérale d'origine.n
