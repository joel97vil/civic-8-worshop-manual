Description des systèmes d'alimentation et d'échappement - Système de commande électrique

Système de commande électronique


Les fonctions des systèmes d'alimentation et antipollution sont gérées par le module de gestion du moteur (ECM).

Auto-diagnostic

L'ECM détecte une panne d'un signal d'un capteur ou d'une autre unité de commande et enregistre un code défaut temporaire ou permanent dans une mémoire effaçable (RAM). Selon la panne, un code est mémorisé au premier cycle de trajet ou au second. Quand un code est mémorisé, l'ECM allume le témoin MIL en fournissant une masse à son circuit.

  • Méthode de détection sur un cycle de trajet
    Quand une panne survient dans le signal d'un capteur ou d'une autre unité de commande, l'ECM mémorise un code pour la panne dans la RAM et allume immédiatement le MIL.

  • Méthode de détection sur deux trajets
    Quand une anomalie survient dans le signal d'un capteur ou d'une autre unité de commande au cours du premier trajet, l'ECM mémorise un code temporaire dans la RAM. A ce moment le témoin MIL ne s'allume pas. Si la panne se reproduit dans le trajet suivant, l'ECM mémorise un code et allume le MIL.

Fonction sécurité intégrée

Quand une anomalie survient dans le signal d'un capteur ou d'une autre unité de commande, l'ECM ignore ce signal et utilise une valeur pré-programmée qui permet au moteur de continuer à tourner. Un code est mémorisé et le MIL s'allume.

Vérification de l'ampoule du témoin MIL

Lorsque le contact est mis (II), l'ECM fournit une masse au circuit MIL pendant environ 15 à 20 secondes à titre de vérification de l'ampoule. Il s'éteint ensuite ou clignote parfois à 5 reprises dans certaines conditions. Ceci est normal : c'est l'indice de l'autodiagnostic du système antipollution.

Mode de coupure automatique (SSD)

Quand le contact est coupé, l'ECM reste en fonction (jusqu'à 15 minutes). Si le connecteur ECM est débranché à ce moment, il peut être endommagé. Pour annuler ce mode, débrancher le câble négatif de la batterie ou ponter la ligne SCS avec le HDS après avoir coupé le contact.
