Dépistage des pannes : P0630

DTC P0630 :  NIV non programmé ou inexact


REMARQUE :
  • Avant de dépister les pannes, noter toutes les données d'image figée et les instantanés puis relire les généralités au sujet du dépistage.
  • Ce code est mémorisé uniquement quand l'ECM ne connaît pas le NIV du véhicule. Utiliser le HDS pour saisir l'information manquante de NIV.

1.Mettre le contact (II).

2.Vérifier le NIV au HDS.

Le HDS affiche le NIV du véhicule ?


OUI - Passer à 5.


NON - Aller à 3.


3.Au HDS, saisir le NIV dans l'ECM.

L'écrab affiche COMPLETE (achevé) ?


OUI - Passer à 5.


NON - Aller à 4.


4.Lire les codes au HDS.

Le DTC P0603 est-il indiqué ?


OUI - Diagnostiquer le code P0603.n


NON - Mettre l'ECM à jour s'il ne comporte pas le dernier logiciel ou remplacer l'ECM et contrôler une nouvelle fois. Si l'anomalie/indication disparaît avec un ECM en bon état, remplacer l'ECM d'origine.n


5.Effacer le code à l'aide du HDS.

6.Couper le contact.

7.Mettre le contact on (II), et attendre 5 secondes.

8.Rechercher les DTC temporaires ou permanents avec le HDS.

Codes temporaires ?


OUI - Si le code P0630 est mémorisé, mettre l'ECM à jour s'il ne comporte pas le dernier logiciel ou remplacer l'ECM et contrôler une nouvelle fois. Si d'autres DTC ou DTC temporaires sont indiqués, les diagnostiquer.n


NON - Panne intermittente, système en ordre pour le moment.n
