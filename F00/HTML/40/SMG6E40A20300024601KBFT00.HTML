Remplacement de l'ECM

REMARQUE : Si le diagnostic conduit à remplacer l'ECM après sa substitution, commencer par reposer l'ECM d'origine.

1.Disposer du code antivol audio.

2.Raccorder le HDS au connecteur de liaison des données (DLC) (A) situé sous le tableau de bord du côté du conducteur.

 

3.Mettre le contact (II).

4.Le HDS doit communiquer avec le véhicule et l'ECM. Si ce n'est pas le cas, diagnostiquer le circuit DLC.

5.Déposer la batterie.

6.Déposer le couvercle (A).

 

7.Déposer les boulons (D) puis l'ECM (E).

 

8.Débrancher les connecteurs A, B et C de l'ECM.

NOTA : Les connecteurs ECM possèdent les symboles A, B et C (A=¨, B=[utri], C=¡) gravés en vue de leur identification.

9.Poser l'ECM et la batterie dans l'ordre inverse de dépose.

10.Sauf KN : Mettre le contact (II).

NOTA : Code P0630 - NIV non programme ou en désaccord - le NIV n'a pas été programmé dans l'ECM; l'ignorer et poursuivre.

11.Au HDS, saisir le NIV dans l'ECM.

12.Réécrire le code d'immobiliseur par la méthode de remplacement de l'ECM dans le HDS. Il permet de démarrer le moteur.

13.Réinitialiser l'ECM à l'aide du HDS.

14.Effectuer l’apprentissage de ralenti ECM.

15.Effectuer l'apprentissage du motif CKP.

16.Saisir le code antivol audio et régler l'horloge.
