Dépistage des pannes : U0423 (184-8)

DTC U0423 :  Défaillance F-CAN (Module de commande des indicateurs)


REMARQUE : Avant de procéder au dépistage des pannes, enregistrer toutes les données figées et relire les généralités au sujet du dépistage.

1.Mettre le contact (II).

2.Effacer le code à l'aide du HDS.

3.Rechercher les DTC temporaires ou permanents avec le HDS.

DTC U0423 indiqué ?


OUI - Remplacer le module de commande des indicateurs (compte-tours) par un module de commande des indicateurs en bon état,, puis revérifier. Si le code U0423 n'est pas mémorisé, remplacer le module de commande d'indicateurs (compte-tours) d'origine.n


NON - Panne intermittente, système en ordre pour le moment.n
