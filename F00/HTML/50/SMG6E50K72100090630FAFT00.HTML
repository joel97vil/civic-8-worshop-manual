Dépistage des pannes : P0630 (139-1)

DTC P0630 :  VIN Non programmé ou En désaccord


NOTA :
  • avant de procéder au dépistage des pannes, enregistrer les données figées et relire les généralités au sujet du dépistage.
  • Ce code est mémorisé lorsque l'ECM ne détient pas d'informations sur le VIN du véhicule. Utiliser l'HDS pour saisir les informations VIN manquantes.

1.Mettre le contact (II).

2.Contrôler le VIN avec l'HDS.

L'HDS affiche-t-il le VIN du véhicule ?


OUI - Passer à 5.


NON - Passer à 3.


3.Saisir le VIN dans l'ECM via l'HDS.

L'écran affiche-t-il COMPLETE (terminé) ?


OUI - Passer à 5.


NON - Passer à 4.


4.Rechercher les codes avec le HDS.

Code P0603 mémorisé ?


OUI - Passer au dépistage du code P0603.n


NON - mettre à jour l'ECM s'il ne comporte pas le dernier logiciel ou remplacer l'ECM par un ECM en bon état, puis revérifier. Si le symtôme/l'indication disparaît avec un ECM en bon état, remplacer l'ECM d'origine.n


5.Effacer le code à l'aide du HDS.

6.Couper le contact.

7.Mettre le contact (II) et attendre 5 secondes.

8.Rechercher les codes temporaires ou permanents avec le HDS.

Codes permanents ou temporaires ?


OUI - Si le code P0630 est mémorisé, mettre l'ECM à jour s'il ne comporte pas le dernier logiciel ou remplacer l'ECM par un ECM en bon état, puis revérifier. Si d'autres codes temporaires ou permanents sont affichés, les diagnostiquer.n


NON - Panne intermittente, système en ordre pour le moment.n
