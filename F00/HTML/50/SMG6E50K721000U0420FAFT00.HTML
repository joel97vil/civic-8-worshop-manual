Dépistage des pannes : U0420 (184-13)

DTC U0420 :  Défaillance F-CAN (Unité de commande EPS)


REMARQUE : Avant de procéder au dépistage des pannes, enregistrer toutes les données figées et relire les généralités au sujet du dépistage.

1.Mettre le contact (II).

2.Effacer le code à l'aide du HDS.

3.Rechercher les DTC temporaires ou permanents avec le HDS.

Code U0420 mémorisé ?


OUI - Remplacer l'unité de commande EPS par une unité de commande EPS en bon état, puis revérifier. Si le code U0420 n'est pas mémorisé, remplacer l'unité de commande EPS d'origine.n.


NON - Panne intermittente, système en ordre pour le moment.n
