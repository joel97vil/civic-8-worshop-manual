Système de commande électronique


Les fonctions des systèmes d'alimentation et antipollution sont gérées par le module de gestion du moteur (ECM).

Auto-diagnostic

L'ECM détecte une panne d'un signal d'un capteur ou d'une autre unité de commande et enregistre un code défaut temporaire ou permanent dans une mémoire effaçable (RAM). Selon la panne, un code défaut permanent est mémorisé au premier cycle de trajet ou au second. Quand un code est mémorisé, l'ECM allume le témoin MIL en fournissant une masse à son circuit.

  • Méthode de détection sur un trajet
    Quand une panne survient dans le signal d'un capteur ou d'une autre unité de commande, l'ECM mémorise un code pour la panne dans la RAM et allume immédiatement le MIL.

  • Méthode de détection en deux trajets
    Quand une anomalie survient dans le signal d'un capteur ou d'une autre unité de commande au cours du premier trajet, l'ECM mémorise un code temporaire dans la RAM. A ce moment le témoin MIL ne s'allume pas. Si la panne se reproduit dans le trajet suivant, l'ECM mémorise un code et allume le MIL.

Fonction sécurité intégrée

Quand une anomalie survient dans le signal d'un capteur ou d'une autre unité de commande, l'ECM ignore ce signal et utilise une valeur pré-programmée qui permet au moteur de continuer à tourner. Ceci mémorise un code et allume le MIL.

Test d'ampoule MIL

Lorsque le contact est mis (II), l'ECM fournit une masse au circuit MIL pendant deux secondes à titre de vérification de l'ampoule.
