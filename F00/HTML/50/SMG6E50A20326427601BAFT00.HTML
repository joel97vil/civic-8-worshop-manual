Purge d'eau du filtre à carburant

1.Déposer le filtre à air.

2.Mettre un récipient adéquat sous le filtre à carburant pour récupérer l'eau.

3.Connecter le flexible (A) à la vis de purge (B).

 

4.Desserrer la vis de purge et purger l'eau du filtre à carburant.

5.Serrer fermement la vis de purge et débrancher le flexible.

6.Démarrer le moteur et contrôler la présence d'eau dans le filtre à carburant (A) sur l'écran d'informations (B).

  • Si le témoin d'eau dans le filtre à carburant est allumé, passer à 7.
  • Si le témoin d'eau dans le filtre à carburant n'est pas allumé, la purge d'eau du filtre à carburant est achevée.

 

7.Débrancher le connecteur 2P du contacteur de niveau d'eau dans le filtre à carburant, puis revérifier le témoin d'eau dans le filtre à carburant.

  • Si le témoin d'eau dans le filtre à carburant est allumé, réparer le court-circuit du câble entre le connecteur de niveau d'eau du filtre à carburant et le module de commande d'indicateurs (compte-tours).
  • Si le témoin d'eau dans le filtre à carburant n'est pas allumé, remplacer le contacteur de niveau d'eau dans le filtre à carburant.

8.Purger le circuit d'alimentation.
