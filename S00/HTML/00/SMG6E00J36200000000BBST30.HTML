Puesta en servicio forzada de la pantalla del sistema de navegación

Procedimiento de arranque y menú de diagnóstico


Herramientas especiales necesarias
Conector de servicio SCS (  07PAZ-0010100)
 



1.Conecte el conector de servicio SCS (A) al conector de comprobación de servicio del sistema de navegación (B), situado detrás de la unidad de navegación.

 

2.Gire la llave de contacto a la posición ON (II).

3.Compruebe que se activa el sistema y que, a continuación, la pantalla cambia a ‘‘Enlace con el sistema de navegación".

NOTA: Si el sistema no efectúa la representación de la pantalla ‘‘Enlace con el sistema de navegación", consulte el código "no se representa ninguna ilustración".
